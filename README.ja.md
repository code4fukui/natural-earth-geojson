# Natural EarthデータのGeoJSON

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

[Natural Earth](http://www.naturalearthdata.com) は、1:10m、1:50m、および1:11000万のスケールで利用可能なパブリックドメインの地図データセットです。元のベクターデータは[ESRI shapefiles](http://www.esri.com/library/whitepapers/pdfs/shapefile.pdf)として提供されています。このリポジトリは、ウェブマッピングやその他のアプリケーションで簡単に利用できるように、同じデータを[GeoJSON](http://geojson.org)に変換して提供しています。

各GeoJSONファイルは、ファイルサイズを小さくするために圧縮された7-Zipアーカイブ（`.7z`）形式でも提供されています。

<img src="logo.png" alt="Natural Earth GeoJSON Logo">

## 使用方法

このデータは、リポジトリをクローンするか、またはフォルダから個々のファイルを直接ダウンロードすることによって使用できます。データはスケールとテーマによって組織されています：

-   `10m/` (1:10,000,000)
-   `50m/` (1:50,000,000)
-   `110m/` (1:110,000,000)

各スケールディレクトリ内では、データはさらに `cultural/` と `physical/` のテーマに分割されています。

## 変換手順

shapefileからGeoJSONへの変換は、[Geospatial Data Abstraction Library](http://www.gdal.org) (GDAL) から提供される[ogr2ogr](http://www.gdal.org/ogr2ogr.html)というコマンドラインユーティリティを使用して行われます。インストール手順やバイナリはGDALのウェブサイトで確認できます。Debianベースのシステムでは、`gdal-bin`パッケージに含まれています。

## データバージョン

このリポジトリのデータは、Natural Earth [バージョン 4.0.0](http://www.naturalearthdata.com/updates/mail.cgi?flavor=archive;list=updates;id=20171103122417) に基づいており、2017年11月3日にリリースされました。

## 注意事項

Natural Earthの[紛争地域に関する免責事項](http://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-0-countries/)に基づいて:

> Natural Earth Vectorは、国々の境界線を事実上の状況に基づいて描画しています。私たちは、現地で実際に状況を管理している主体を示しています。ご希望の政治的立場に合わせて、私たちの紛争地域のテーマを自由に組み合わせてご利用ください。

## ライセンス

Natural Earth データセットはパブリックドメインにあります。
