# Natural Earth データの GeoJSON 版

[Natural Earth](http://www.naturalearthdata.com)は、1:10m、1:50m、1:110mのスケールでプラブリックドメインの地図データを提供しています。ベクターデータは ESRI シェイプファイルで配布されていますが、このリポジトリでは同じデータを GeoJSON 形式に変換したものを提供しています。さらに圧縮版も含まれています。

## 主な機能

- 自然地理と人文地理のデータが多数用意されています
- 国境、行政区画、主要都市、河川、湖沼などのデータが含まれています
- 1:10m、1:50m、1:110mのスケールバージョンが利用可能
- GDAL の ogr2ogr コマンドを使ってシェイプファイルからGeoJSON に変換しています

## データ

以下の主なデータテーマが含まれています。

### 人文 
- 国
- 紛争地域
- 第一行政区画
- 主要都市
- 都市エリア
- 公園・保護地域
- 太平洋諸国の地域区分
- 海洋境界線

### 自然地理
- 海岸線
- 陸地
- 海洋
- 小島嶼
- サンゴ礁
- 地理名称
- 河川・湖沼
- 氷河地域
- 海底地形
